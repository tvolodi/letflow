## Coverage limits (stated, not hidden)

- **T11 failing branch is not reachable** through the public API: `tenant_id_for_schema_name/1` only
  validates the `tenant_<32 hex>` shape, and every earlier completion-hop step runs against that same
  prefix, so a prefix that fails derivation never reaches it. The T11 test is a control for the lazy half
  of 3.3a (a hop activating no catalog node performs no derivation). The failing branch is covered only by
  its typed-return shape in code review.
- **Escalation-timer site** (`advance_after_escalation_timer_fired`) is not driven; the same
  `prepare_service_task_dispatch_abort_on_empty_url` wrapper is exercised by T8a/T8b (m6b kills a change to
  that wrapper). Recorded per the design's T8 allowance.
- Registration-time SSRF validation (design 7.4) and e2e (FRONTEND-DEV) are out of this file's scope.
