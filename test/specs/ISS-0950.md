## Deviation from the design (reported)

U-NODNS (b): the design says `:erlang.trace(self(), true, [:call])`. A process does not
receive its own trace messages (measured: zero messages, so `refute_receive` would be
vacuous). The test uses a separate tracer process (`{:tracer, pid}`) that forwards messages
to the test process, and adds a positive control (the real resolver is traced) to prove the
harness is live.
