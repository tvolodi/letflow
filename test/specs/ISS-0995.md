# ISS-0995 / Q-976 -- authorization-denial attribution log line, test spec

Design (governs): `lib/letflow/design/iss0995-authz-deny-attribution-log.md`, section 13 (tests (a)-(j), fail-first, mutants).
Run: `WF03-Q976-20261006`. Code under test: `Letflow.Api.AuthzDenyLog` (new) and the one call in the `:Deny403` branch of
`Letflow.Plugs.Authorize.call/2`. Test file: `test/letflow/api/authz_deny_log_test.exs`
(`use Letflow.DataCase, async: false`: `capture_log`, Application env, the platform-tenant pin and `:persistent_term` are VM-global).

State isolation: `setup` calls `AuthzDenyLog.reset/0`, saves `:secrets_master_key`, `:authz_deny_log_window_s` and
`:authz_deny_log_clock`, sets the window to `0` (every denial logs) unless a test is about sampling, and restores all three plus
`reset/0` in `on_exit`. The platform-tenant pin is restored by `PlatformTenantFixture`'s own `on_exit`. Sampling tests fix the master
key so slot indexes are deterministic (no 1-in-4096 collision flake). Clock: an `:atomics` cell read by an injected fun; no sleeps.
