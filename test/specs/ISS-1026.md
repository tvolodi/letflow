# ISS-1026 test spec: approve/reject re-check the review's stored source/target tenant ids

Q-1008 / GH #2305. Code: `lib/letflow/routers/promotions.ex` (`handle_approve`, `handle_reject` call
`stored_tenants_authorized?/3`). Test: `test/letflow/routers/promotion_approve_reject_stored_ids_test.exs` (8 tests,
`async: false`, partition 3).

Setup: three provisioned tenants, pin on P. The non-operator caller is `PLATFORM_ADMIN` of tenant A (holds
`:PromotionsManage`, is not the pinned platform tenant). Requests carry a FIXED caller user id (the shared
`Fixture.router_conn/5` mints a fresh id per call and could not reproduce requester == caller).
The baseline for every denial is the observable (status, body, every header but `x-request-id`) of the same call
for a nonexistent review id.

## Criterion to test mapping

| Acceptance criterion | Test | Why it exists |

  requested_by, def_type, def_id, created_at, row_version), `GET /promotions/:id` (assertion run counts and failing

  as for a nonexistent id), so the id's existence is not revealed by it.
