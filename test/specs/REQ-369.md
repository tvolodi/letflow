## A note on the module-scope re-entrancy guard

`OidcCallbackPage.tsx` uses a module-scope `let _callbackStarted = false` flag (documented
in the file's own comment, lines 12-22) to survive React StrictMode's double-invoked
effect. Because it is module state, not component state, it persists across `render()`
calls within the same test file unless the module is freshly reloaded — a naive two-test
file sharing one static `import OidcCallbackPage from '@/pages/OidcCallbackPage'` would
have its second test's effect silently no-op (verified empirically: an earlier draft of
this file, written with a single static top-level import and no `vi.resetModules()`,
was run and the second test hung/timed out waiting for a `navigate` call that never came,
because `_callbackStarted` was already `true` from the first test's render). Each test
now calls `vi.resetModules()` and dynamically `await import('@/pages/OidcCallbackPage')`
so the flag starts fresh per test; the `vi.mock(...)` registrations (hoisted, module-path
keyed) survive `resetModules()` and still apply to the freshly-loaded module instance.

## Why this requirement needs no fail-first-against-pre-fix-code demonstration

REQ-369 is a WF-02 (new-code) requirement, not a WF-03 regression — `PlatformDashboardPage.tsx`
did not exist before this change, and `OidcCallbackPage.tsx`'s `navigate()` call was
unconditional. There is no meaningful "run these tests against the pre-fix tree" step:
the pre-fix tree has no `PlatformDashboardPage` module to render at all (a bare
import-and-render would throw a module-not-found error, which proves the file didn't
exist, not that the tests exercise real logic), and this is a WF-02 (not WF-03) run, so
the mutant-testing obligation for the "code under test did not exist" case
(`docs/agents/workflows/WF-03_issue_resolving.md`) does not apply — that obligation is
scoped to WF-03 regression runs. Each test case above is instead reasoned against a
concrete, plausible wrong implementation (stated per case in the tables above), matching
REQ-362's own precedent for a new-code requirement's test spec.
