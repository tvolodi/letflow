# Test spec: REQ-435 -- platform tenant-login directory (data layer, writers, backfill)

Design: `lib/letflow/design/req434-email-first-login-directory.md` section 15.1.
Author: TEST-DESIGNER. Why each test exists is stated next to it; the table is the
criterion -> test map. All DB tests use real Postgres and real provisioned tenant
schemas via `test/support/login_directory_fixture.ex` (a thin wrapper over
`Letflow.TenantFixture` + `SandboxAutoMode.provision!/2`: provisioning commits,
the test body is rolled back).

Files: `test/letflow/login_directory_test.exs` (LD), `test/letflow/login_directory/plan_user_change_test.exs` (PLAN),
`test/letflow/login_directory/backfill_test.exs` (BF), `test/mix/tasks/letflow.backfill_login_directory_test.exs` (TASK),
`test/letflow/identity_login_directory_test.exs` (ID), `test/letflow/routers/identity_login_directory_test.exs` (RT),
`test/letflow/identity_login_directory_concurrency_test.exs` (CONC).

## Recorded gaps (not silent)

- `mix ecto.rollback` / `mix ecto.migrate` real output (criterion 1) is not an ExUnit test; see above.
- `System.halt(1)` branches of the mix task (failed tenant, missing pepper) cannot run inside the test VM; the failure behaviour is tested at `Backfill.run/1` and the halt lines by source inspection (TASK last test).
- Pepper boot checks (`config/runtime.exs`: absent, malformed, trivial, equal to master key) are not in this file set; design 15.1 lists `login_directory_runtime_config_test.exs`, modelled on `secrets_runtime_config_test.exs`.
- Same-identity JIT username race (the `{:existing, _}` branch via the username index) is reachable only by a genuine race; CONC exercises it statistically (4 rounds), the deterministic different-identity branch is in ID.
- Callers: six existing test files pass `login_directory: :skip` although their fixtures DO have a `tenants` row (design 15.1 allows `:skip` only "where the fixture prefix has no tenants row"); flagged to ORCH as a minor deviation.
